Issue 1 — Character encoding broken throughout (publish blocker)

Every em-dash and emoji landed as broken UTF-8 bytes

The file appears to have been saved as Latin-1 / Windows-1252 instead of UTF-8. Em-dashes (—) and arrows / emoji landed as the literal byte sequence â or ð. If committed as-is, the LIVE site renders those broken characters verbatim — readers will see â wherever you intended an em-dash.
