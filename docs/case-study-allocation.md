## Process

1. **Before drafting any new post:** read this matrix.
2. **After drafting:** update this matrix with the new anchors + uses.
3. **At feedback stage:** flag any verbatim reuse of "primary anchor" content as BLOCKED.
4. **For pacing-style posts (where Maryssa Payne fits):** verify which metric/framing the previous post used, pick a different one.
5. **When new sheet data arrives:** add new properties to the "Available" rows so the cupboard isn't bare for posts 4–10.
